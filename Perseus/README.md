# Perseus project website

Published endpoint: `https://huicir.github.io/Perseus/`.

This page is a curated project presentation of the author-supplied manuscript and character set. Full manuscript PDFs and LaTeX sources are not included. Character PNGs are copied unchanged. Figure PNGs are complete renders of the supplied vector figures; provenance is recorded in `assets/figures/sources.json`.

`data.js` holds reported numeric results. `locales.js` holds English/Chinese copy. `site.js` implements a shared map camera, route-following hero, eight natural-scroll, viewport-sized story acts with native scroll snapping, the full-map atlas, research scroll dialogs, an automatic, single-play wave animation, metric/result tabs and figure enlargement. Each act has its own composition; portrait screens place the illustrated journey below the story. Settled research chapters open their related scroll automatically after a short reading pause. Dismissing it keeps the current chapter open; the visible chapter link can reopen it. Modal views lock the background journey and preserve the return position. The project defaults to English with an independent language preference; legacy homepage preferences are not inherited. The author-supplied NN logo is copied unchanged and framed in CSS. World textures are decoded before reveal; a two-request queue loads the current cast and prefetches the next chapter, with three bounded attempts for transient failures. Paper/atlas/lightbox images can retry without replacing a newly selected figure. The initial camera is positioned at the requested story chapter before the world appears. Map feathering applies only to the map image, and the backdrop uses paper tones rather than a second, independently positioned map. The equipped half-body image is scaled to match the initial traveler height and its lower edge is softly blended; original character bytes remain unchanged. Project navigation includes GitHub and Paper (temporarily the same GitHub destination pending arXiv). Keyboard access, reduced motion, and scientific tables without JavaScript are supported. The 24-second animation opens on its own receiving view and plays when the Actor, ledger inlet and first source are visible. It pauses offscreen or in a hidden document, restarts on reopening, and holds its final state. Ready observations retain named seals until t+1/t+2; visible paths carry evidence through the ledger inlet to the Actor boundary. Each admission is expanded over 2.8 narrative seconds, with the Actor marker held at that boundary while other pending Futures continue. A second known catalog observation is visibly suppressed without an Actor return path. Route geometry follows actual element positions across viewport and language changes. Reduced motion shows a static completion frame; a bilingual six-stage transcript remains available. The demonstration makes no model or tool requests and represents logical stages, not measured elapsed time.

The page keeps the manuscript's model/sample/metric conditions and its negative results. Main/ablation ES uses binary task success; scaling ES uses native partial credit. Native harness adapter validations are not presented as manuscript benchmark results.

The three runtime equations are precompiled into KaTeX HTML and accessible MathML. Desktop uses full-width expressions; small screens use equivalent aligned expressions without shrinking the type. CSS and WOFF2 fonts are vendored under `assets/vendor/katex-0.19.0/`, with license and source integrity metadata. `math.js` stores the three definitions and compiled wide/compact forms and can regenerate them with the official KaTeX API. The browser does not load a math renderer or contact a CDN.
