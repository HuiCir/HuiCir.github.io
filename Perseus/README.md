# Perseus project website

Published endpoint: `https://huicir.github.io/Perseus/`.

This page is a curated project presentation of the author-supplied manuscript and character set. Full manuscript PDFs and LaTeX sources are not included. Character PNGs are copied unchanged. Figure PNGs are complete renders of the supplied vector figures; provenance is recorded in `assets/figures/sources.json`.

`data.js` holds reported numeric results. `locales.js` holds English/Chinese copy. `site.js` implements a shared map camera, route-following hero, eight natural-scroll story acts, the full-map atlas, research scroll dialogs, an automatic, single-play wave animation, metric/result tabs and figure enlargement. Each act has its own composition; portrait screens place the illustrated journey below the story. Keyboard access, reduced motion, and scientific tables without JavaScript are supported. The 24-second animation plays automatically when visible, pauses offscreen or in a hidden document, restarts on reopening, and holds its final state. Reduced motion shows a static completion frame; a bilingual six-stage transcript remains available. The demonstration makes no model or tool requests and represents logical stages, not measured elapsed time.

The page keeps the manuscript's model/sample/metric conditions and its negative results. Main/ablation ES uses binary task success; scaling ES uses native partial credit. Native harness adapter validations are not presented as manuscript benchmark results.
